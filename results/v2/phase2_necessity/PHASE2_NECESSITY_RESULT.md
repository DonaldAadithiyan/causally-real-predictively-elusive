# PHASE2_NECESSITY_RESULT — denoising/noising necessity test for the MVDF set
Generated by `experiments/phase2_necessity_noising.py`. ETTh1 + ETTh2, HTTP mirror. Bounded extension of the intervention-validity work (Document 1 §2.2; Joshi et al. 2026 'Sufficient ≠ Necessary'; Heimersheim & Nanda denoising/noising).

## What each column is

- **`delta_noise`** = E[S_t(MVDF codes → 0) − S_t(clean)] over active windows. Positive ⇒ removing the MVDF set degrades difficulty tracking that other features do *not* reconstruct.
- **`delta_denoise`** = E[S_t(all codes → per-feature mean) − S_t(that, but MVDF codes restored to true values)]. Positive ⇒ restoring *only* the MVDF set recovers difficulty tracking the corruption removed (≈ sufficiency).
- **`random_set_noise_mean±sd`** = same noising with a matched-size random eligible-feature set (5 draws). **`random_dir_noise`** = matched-L2-norm random-direction perturbation of the pre-head token.
- **`natrange_restored_within_5_95pct`** = fraction of restored MVDF activation values inside the 5–95th percentile of each feature's natural active distribution (on-manifold check).

## Reading

**Necessity is not established** — noising the MVDF set does not degrade difficulty tracking beyond the random-set / random-direction controls. The dose-response result remains a *sufficiency* statement only: intervening on these features moves `S_t`, but they are not shown to be necessary (other pathways or redundant features may substitute). State H1c's causal claim as sufficiency, not necessity.

> This does not bear on Phase 3 / the downstream conformal results — it concerns only how strong the *upstream* causal claim (H1c) can be stated.
