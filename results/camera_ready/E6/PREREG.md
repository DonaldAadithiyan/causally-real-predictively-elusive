# E6 — L1 battery on TimeMixer (stretch): pre-registration

Committed before the first E6 run.

## Artifacts
TimeMixer MVDF selections exist (`runs/arch_gen_timemixer/<ds>_seed<s>/mvdf_selection.json`, ETTh1/ETTh2 × 0–2) but no weights or per-window arrays. They are regenerated by re-running the unchanged `experiments/arch_gen_timemixer.py` training prefix (CFG unchanged, CPU, 4 threads, seed `derive_seed(seed, ds)`) and saving arrays. **Gate:** forecaster val MSE and SAE FVU must match `runs/arch_gen_timemixer/AGG_arch_gen.csv` (|diff| < 1e-6) and `select_mvdf_v2` on the regenerated dose sweep must return the stored MVDF set; a cell that fails the gate is reported and analysed with its stored MVDF set flagged as non-reproduced.

## Analyses
1. Phase 3 battery (original definitions), marginal + active-window, with block-bootstrap CI (block 96) of the best-on-eval R².
2. E3 feature sets F0, F1, F1p, F2, F6 with the full E3 estimator grid and CV selection (E3 PREREG items 1–12 unchanged).

## Pre-registered criteria
- C1.1 (TimeMixer): best held-out R² of F0 has CI including 0 or below 0 on ≥ 2/3 seeds per dataset, both batteries.
- C3.1–C3.3 as in E3, restricted to F0, F1, F1p, F2, F6 (3/3 seeds rule for N = 3).
