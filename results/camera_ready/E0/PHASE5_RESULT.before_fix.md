# PHASE5_RESULT — SAE functional reproducibility
Generated by `experiments/phase5_sae_reproducibility.py`. ETTh1 + ETTh2, HTTP mirror. Forecaster trained once per dataset; 3 independent SAEs (seeds 10/20/30) on the same frozen hidden states.

## What this checks

Low reconstruction loss + sparsity does not imply a unique decomposition. This matches features ACROSS independently-trained SAEs by **causal signature** — standardized Euclidean distance in `(P_j, U_j, R_j)` space (pooled-SD units), mutual nearest neighbour — not by decoder-weight correlation (permutation / rotation freedom makes raw coordinate matching a poor criterion). Reported as a curve over match thresholds {0.1, 0.25, 0.5, 1.0} SD; headline table shown at 0.5 SD (the loosest still-meaningful cutoff — a stricter one only lowers the match rate).

Two references for the rate: **`pool_base_rate`** = the same mutual-NN-within-threshold rate over the *whole* candidate pool (does MVDF membership buy extra reproducibility over a generic feature?); **`signature_shuffle_rate`** = rate after breaking the run-0↔run-r correspondence (how dense the signature cloud is — a floor).

## Reading

**Low functional reproducibility** — mean match rate 0.25 at 0.5 SD (shuffle floor 0.25). Individual MVDF feature identity does not survive an SAE reseed by causal signature. H1c's claim must be stated purely at the population level (type-B enrichment is a property of the SAE feature *space*, reproducible in aggregate); no claim about specific features.

> This does not affect H1c's causal validity — the dose-response intervention is real for whatever features a given SAE recovers. It bounds only how much can be said about the *identity* of those features.
